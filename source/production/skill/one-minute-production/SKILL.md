# 一分鐘認識：動畫製作

以實際專案、核定講稿與成功交付紀錄接續工作。新概念先釐清一個學習目標；既有專案先讀其 AGENTS、README、正式版本與 review。沿用已確認需求，不把過往偏好、單次錯誤或歷史工具狀態當成普遍規定。

## 選擇本次階段

- 新增完整系列：讀 [references/prompts.md](references/prompts.md) 的 new-series 工作流，先填系列主題、英文代號、集數、概念與工作區；在使用者授權的範圍內串起製作、品牌、網站、技術經驗與發布。使用者只要規畫或暫不發布時，依該範圍交付，不能把參考檔中的完整授權段落當作新授權。
- 需求與分鏡：讀 references/playbook.md 的 brief-storyboard；只完成可審查的製作單。
- 環境盤點：讀 project-environment，可用 scripts/inspect-project.mjs --project <專案> 唯讀列出文件、腳本名稱、固定版本與工具狀態。此腳本不執行專案 scripts、不讀憑證、不連網。
- 動作與數據：讀 trace-animation；先驗證資料守恆、規則、動作計數，再對到畫面。
- 旁白字幕：讀 voice-caption；先找成功音檔，按實際音訊對時。
- 動作審查：讀 motion-review；優先修理解、連續性與遮擋，再修緩動。
- 正式輸出：讀 render-validation；依授權輸出新檔並驗證真正 MP4。
- 網站交付：讀 publish-brand；依目標專案規則同步課程、路線、關聯及離線包。
- 複用提示：references/prompts.md 提供新增系列完整工作流與八種階段範本；依任務選用，替換變數和授權範圍，不全部串成無條件執行命令。

在一分鐘認識工作區新增或更新系列時，先讀 one_minute/AGENTS.md 的共同品牌規範及 portal/content/brand-guide.md，沿用活潑構圖、霧白／墨綠與藍黃輔色、共用封面和頁面模板。依專案交付流程同步首頁、課程、觀看路線、合理的概念關聯與相關單元連結，整理實際可複用的製作經驗至技術文章、提示詞與技能來源，再同步參考檔及下載包。檢查通過後依既有或當次授權正常推送 GitHub 並確認 Pages；保留課程 id、舊連結、觀看進度與歷史素材。在其他工作區先確認當地路徑與發布目標，不直接套用這些位置。

## 製作約定

本系列常用繁中、約 60 秒、1920×1080／30fps；以既有核定規格為準，保留 30 秒原版等歷史輸出。聲音由專案決定，目前系列正式版多用 Azure 雲哲，不能自行換聲。先量實際語音，再安排畫面與字幕；保留自然速度與完整句尾。

真正製作、修改、預覽或渲染 HyperFrames 動畫時，先使用環境中可用的 hyperframes 技能入口，再依需要讀 core、animation、audio、CLI 等技能。已有專案沿用 package.json 固定版本及正式生成器，不任意重跑 setup 或升級；缺少必要技能或工具時，先保留資料並說明缺項。

所有會消耗 Azure 的配音、試聽與重製，在 animation 工作區都必須走 tools/azure-speech/index.mjs 或 synthesizeAzure，先讀其 README。共用 config/azure-speech.json 與 usage/azure-speech/ledger.json；本機政策為 40 萬提醒、45 萬停止、單次 3000，並套用 31 天保護。首次或換月未知用量不能當零；失敗仍保留預留、不自動重試。不得繞過、複製或回復帳本以增加額度；金鑰不進輸出。這不是帳號全域硬限額。在其他工作區不得假設此入口存在或移植舊用量；先建立當地合法來源與管控，未完成前只做不消耗的工作。

## 驗證與交付界線

- 選擇本次階段需要的動作；提示詞或 skill 本身不構成配音、付費、渲染、發布或搬移的額外授權。已有明確授權繼續有效，不重問；使用者說只規劃或只預覽，就停在該交付。
- 追蹤 before／after、比較、交換、右移、搬盤與候選區間；分清本例、最少、最多、計算與實際示範。
- 條件動畫分開記錄輸入狀態、布林結果與動作，列完整真假組合；或包含兩者皆真，非固定原判斷且不改變輸入狀態。動作中檢查文字遮擋，倒回同一時間需重建相同狀態，詳見 references/playbook.md 的 trace-animation 與 motion-review。
- 時間軸可停、跳、倒回；物件狀態依時間決定。保留素材來源與使用條件；不要公開原始對話、登入資訊或私人帳本。
- ASR 與波形比對只代表相應範圍的驗證，不能宣稱人工逐字聽審。QA 寫本次實際檢查與限制，不沿用舊通過數字。
- 正式 MP4 需驗證規格、完整解碼、實際抽圖、音訊位置與字幕；保留新舊輸出、修改來源與可重建文件。
- 技術文章、講稿與提示詞不冒充已完成影片；網站發布依當地 AGENTS 與當次授權，推送後再確認線上內容。
