# 八組階段提示詞

替換【變數】與當次授權，不把提示詞當作額外的生成或發布授權。

## brief-storyboard｜把一個概念，拆成可製作的分鏡

```text
請先閱讀工作區與目標專案的 AGENTS.md、README、版本設定及既有審查紀錄，沿用已確認需求。區分規劃、已生成、已驗證與未完成；保留原素材及歷史輸出。只執行本次指定階段，不因有提示詞而自行消耗配音額度、渲染或發布。對已授權事項不要重複詢問。

這次只做需求與分鏡，主題為【主題】，看完要理解【單一目標】。
專案位置：【專案路徑】。已確定：【既有選擇】；還沒確定：【待選項】。
以生活或遊戲例子說明，先提供風格選項與逐幕表：規劃時間、教學目的、物件前後狀態、畫面文字及完整繁中旁白。
明確標記示意、縮時及計算結果。檢查容易混淆的術語與既有單元關聯。
本次先不生成媒體或正式影片；交付 BRIEF、STORYBOARD、SCRIPT 與待決問題。
```

## project-environment｜把製作環境，變成可接續的專案

```text
請先閱讀工作區與目標專案的 AGENTS.md、README、版本設定及既有審查紀錄，沿用已確認需求。區分規劃、已生成、已驗證與未完成；保留原素材及歷史輸出。只執行本次指定階段，不因有提示詞而自行消耗配音額度、渲染或發布。對已授權事項不要重複詢問。

列出 package.json 的腳本用途、固定 CLI 版本、正式生成器、素材／字幕／成功音訊位置，以及目前正式交付版本。
檢查 Node、FFmpeg、FFprobe 是否可用；不要重裝、升級、重跑 setup 或改寫素材。
```

## trace-animation｜讓動畫跟著資料走，而不是靠畫面猜

```text
請先閱讀工作區與目標專案的 AGENTS.md、README、版本設定及既有審查紀錄，沿用已確認需求。區分規劃、已生成、已驗證與未完成；保留原素材及歷史輸出。只執行本次指定階段，不因有提示詞而自行消耗配音額度、渲染或發布。對已授權事項不要重複詢問。

請為【專案路徑】的【演算法或操作】建立可重播的 animation-trace。
資料為【初始資料】，規則為【規則】，需要計數【比較／交換／右移／搬動等】。
先產生事件的 before／after、動作與順序，獨立驗證資料守恆、操作是否合法及最後結果。
再把事件對到畫面、計數、音效與提示；快轉仍保留所有必要操作。
明確區分本例次數、最好／最差上限、實際示範與計算結果。這次先完成 trace 與驗證，不重新配音或輸出 MP4。
若是條件或布林邏輯動畫，列完整真假組合，固定原判斷，分開記錄輸入狀態、判斷結果與動作。驗證或包含兩者皆真、非不改變原狀態；每個獨立示範重新設置狀態。
若是迴圈動畫，分開記錄條件檢查、本體動作與完成輪數；重複直到需覆蓋起初成立的零次案例。驗證每輪先檢查、最後成立時不再做本體，以及離開後的下一個指令。
示範不停止的迴圈時，標明只展示有限步與教學暫停；驗證狀態是否朝停止條件改變。更新後尚未重算的條件不要冒充目前結果，並區分刻意持續執行與不符合任務的錯誤。
```

## voice-caption｜先量到聲音，再安排字幕與畫面

```text
請先閱讀工作區與目標專案的 AGENTS.md、README、版本設定及既有審查紀錄，沿用已確認需求。區分規劃、已生成、已驗證與未完成；保留原素材及歷史輸出。只執行本次指定階段，不因有提示詞而自行消耗配音額度、渲染或發布。對已授權事項不要重複詢問。

請處理【專案路徑】的旁白與繁體字幕。先核對 SCRIPT、既有成功音訊、字幕與用量紀錄。
本次模式：【只檢查／重用音訊重新對時／已授權的新配音】。
聲音沿用【已確認聲線】，不自行換聲；重用成功音檔，不以試聽反覆生成。
如需 Azure，先讀 tools/azure-speech/README.md，僅用共用 guard；未知用量先停止生成，不自動重試。
依實際音訊及詞組時間安排字幕與畫面，保留自然速度和完整句尾。字幕逐字接回核准稿，保留 ASR 差異。
交付音檔／字幕對照、最後語音結尾時間、實際做過的檢查及尚待聽審事項；不輸出金鑰或帳本私密內容。
若計數語句快於操作，先核對無語音間隙，再加入必要停頓並重算字幕與動作，不用加速或重配掩蓋對時問題。
```

## motion-review｜把動畫審查，變成製作原則

```text
請先閱讀工作區與目標專案的 AGENTS.md、README、版本設定及既有審查紀錄，沿用已確認需求。區分規劃、已生成、已驗證與未完成；保留原素材及歷史輸出。只執行本次指定階段，不因有提示詞而自行消耗配音額度、渲染或發布。對已授權事項不要重複詢問。

請審查【專案路徑】的現有動畫，先以教學理解與物件連續性排序問題，再看緩動、層級、對比與閱讀時間。
逐幕列「問題、時間點、原因、修正方式、驗證狀態」。
進場依目的選 ease-out 或自訂曲線；等速動作可保留 linear，不為展示效果添加無關回彈。
確認 paused timeline、固定狀態、媒體時間與字幕區安全。測試前進、倒回及場景邊界。
只修本次指定問題，保留原素材和成功音訊；先提供修正版預覽與實際驗證紀錄，是否正式渲染依既有授權。
加入角色跨過文字區、開門、狀態重置等動態時點，檢查遮擋與對比；將時間軸先往後再倒回同一時間，比對物件狀態與音訊位置。
```

## render-validation｜預覽正常之後，還要驗證真正的 MP4

```text
請先閱讀工作區與目標專案的 AGENTS.md、README、版本設定及既有審查紀錄，沿用已確認需求。區分規劃、已生成、已驗證與未完成；保留原素材及歷史輸出。只執行本次指定階段，不因有提示詞而自行消耗配音額度、渲染或發布。對已授權事項不要重複詢問。

先核對固定 CLI 版本、既有 scripts 與正式來源；保留舊成片及成功音訊，不重跑初始化。
```

## prompts-to-skill｜把成功流程，封裝成提示詞與 skill

```text
請先閱讀工作區與目標專案的 AGENTS.md、README、版本設定及既有審查紀錄，沿用已確認需求。區分規劃、已生成、已驗證與未完成；保留原素材及歷史輸出。只執行本次指定階段，不因有提示詞而自行消耗配音額度、渲染或發布。對已授權事項不要重複詢問。

請把【已完成的製作流程／專案紀錄】整理成可重複使用的 skill。
先區分現行規則、歷史案例與未驗證想法，保留可追溯的來源。
SKILL.md 僅放必要決策與操作界線；長篇技術、提示詞與案例移到 references，確實可重複的機械工作才做 scripts。
描述清楚適用與不適用情境，沿用使用者已授權範圍，不把單次偏好或過往問題變成普遍禁令。
驗證前言、引用與腳本行為；試用不得生成真實配音或發布。交付可安裝資料夾、使用範例、驗證結果與限制。
```
