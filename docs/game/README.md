## 戰鬥與野外生態

普通怪物在領地中遊走或巡邏，發現主角或夥伴後先警戒再追擊。離開領地、或失去目標後，怪物會走回原處；返回時不回血、不傳送。首領另有原本的預警與彈幕。

外層原野分為九個棲地，每個棲地目標四隻，正常首次進入合計 36 隻，上限 40 隻；原有較小野外地圖維持約四隻。各章有三種區域怪物，村口周邊保留安全範圍。怪物在進入地區時已經存在。同次探索不會定時補怪；清空後可安心探索。離開地區至少兩分鐘、且安寧時間已結束，再回訪才恢復普通怪物。巢穴清除可延長安寧，首領與事件守衛不重生。暫停與離線不累計時間。

可在地圖直接揮劍，或使用長槍、戰斧、防禦、衝刺與三種法術。弱點、射程、地形遮擋、裝備與補給會影響戰鬥。裝備各章強化上限為 +3／+6／+9。

## 操作

| 操作 | 鍵盤 |
|---|---|
| 移動 | WASD／方向鍵，也可點地面尋路 |
| 調查／交談／推進對話 | 空白鍵；E／Enter 也可 |

| 防禦／映光防禦 | 按住 L；習得後舉盾瞬間可完美防禦 |
| 蓄力斬 | 習得後按住 H，蓄滿後放開 |

| 暫停與設定 | Esc |

右手 H／J／K／L 為同排戰鬥鍵，U／I／O 在上一排；左下 Z／X／C／V 為選單。畫面按鈕按相同位置排列。三個道具欄預設指定紅葉藥水、星露、月露精華，可改指定六種消耗品；只在持有時顯示名稱、圖示與數量，數量為零時顯示暗色空欄位。不會自動換成另一種藥水。欄位配置保存在目前瀏覽器偏好中，不隨角色存檔匯出。

優先辨識鍵盤實體位置，切換中文輸入法仍可操作；輸入姓名與操作下拉選單時不攔截文字輸入。對話、存讀檔、加工與確認畫面不受選單快捷鍵切換影響。保留 Shift 作衝刺替代鍵；空白鍵專用於互動與對話，攻擊僅使用 J；舊的 R／F／Q／T／M 不再對應原功能，I 現為治療法術。

手機提供方向鍵、攻擊、衝刺、互動、防禦與法術按鈕。接近門口即自動進出，無須按互動鍵。

## 裝備、隱藏加工與耐久（BUILD 20261026.14）

背包 Z 提供武器、身體防具、護符三個獨立欄位，顯示裝備等級、剩餘耐久與換裝攻防比較。初始長劍與護甲兩件之外，每章各有五件普通取得與三件特殊加工，共二十六件實際裝備；護符另有不裝備選項。裝備等級是強度及耐久的基準，不作硬性穿戴門檻，鼓勵自由探索。武器及身體防具各沿用原來的共用強化等級，三章上限 +3／+6／+9。

青苔村、風鈴港、晨星要塞北側各有一間工坊，分別由苔爐匠・洛木、潮紋匠・汐蘭、星鑄師・嵐恩加工。九種材料藏在十八處洞窟與野外藏點；靠近才發現，互動採集一次。每章材料總量足以製作該章三件特殊裝備，第一章的材料不需要第二、三章的鉤索或手甲。交談後手札會記下配方與材料線索，可追蹤及查看可回報狀態。加工須在對應工匠身旁，會消耗材料及金幣，不會重複製作或重複扣料。

耐久依裝備等級增加：普通武器及護符為 36 + 6 × 裝備等級，普通身體防具為 14 + 2 × 裝備等級；特殊加工裝備乘 1.6 並四捨五入。初始長劍耐久 42、初始護甲 16。普通裝以適用等級附近約兩級的戰鬥使用量為設計目標，仍需真人試玩校準，並非升兩級就自動損壞。

武器命中敵人、實際割草或破開藤蔓才耗耐久 1，蓄力命中耗 2；空揮、未命中或被影化閃避不扣，同次攻擊命中多個目標只計一次。護甲承受攻擊、普通防禦及完美防禦都耗耐久 1，沒有命中的攻擊不扣；有效攻擊、成功施法或承受攻擊時耗護符耐久 1。最後一次使用仍生效，之後歸零。武器損壞後改為低攻擊、短距離的徒手，無法蓄力斬或割開藤蔓；身體防具及護符損壞後停止提供效果。耐久不足與損壞有提示，HUD 顯示三欄耐久。

歸零前可找任何村鎮工匠修理，按缺損比例收費；歸零後可花完整修理費的兩倍重鑄，不必重新尋找有限的隱藏材料。住宿、升級、死亡與讀檔不會免費補滿耐久。舊存檔的武器、護符與強化保留，首次導入耐久時為完整值；新存檔保存每件裝備的實際剩餘值、材料、採集、配方與追蹤。

`npm run check:equipment` 驗證三欄、材料取得、九項加工、修理／重鑄、損壞效果、舊存檔及每章種類分配。完整裝備清單見 `GEAR.md`，真實瀏覽器與兩級使用量尚待手動試玩確認。

## 餘火石像與聖域石盤（BUILD 20261029.36）

第二章餘火迷廊改為老師留下的守路石像。西側石碑最多容納十二枚前進、左轉、右轉或推石符石，可撤回、清空，再喚醒石像。石像依序行動，能踏過玩家無法通行的餘燼；走錯會停在障礙前，改寫符石或搖風鈴可重新開始，不消耗道具。石像推開石塊、到達踏板後，南側窄道盡頭的橋會升起；玩家須走到另一側轉動石柄才完成機關。老師的第三頁仍在原本東南石壁，接續巡守者與織火者的故事。

石像行動與轉角、石塊位置、符石進度可存檔；遊戲暫停或開選單時停止行動，離開或戰敗也會停止。返回後可沿原方案從起點重跑。踏板啟動後不再接受重置，確保已過橋者仍能返回；完成後保留通行與一次性獎勵。舊存檔已解開者直接保留通路；尚未解開者以新機關開始。石像在灰燼裡的路徑與玩家通路分開處理。

第三章天光聖域的守護者門庭改為三環石盤。探索門庭找回日、月、星三枚誓印，分別喚醒外、中、內環柄。外環帶動三環，中環帶動中、內兩環，內環獨轉；每環依日、月、星循環。外日、中月、內星對齊後，調查中央石盤完成守護誓約。歸位石柄只重置環位，保留已找到的誓印；舊徽章線索與下一層光影選擇仍使用原本流程。

東北側舊碑可用螢光提燈讀出額外誓詞，保留閱讀進度且不消耗工具；沒有提燈也能完成主線。碑文不新增結局門檻。舊存檔已通行的門庭維持解開，重複互動不重複發獎。
