## 角色能力與換裝預覽（BUILD 20261026.21）

按 Z 在背包頂部查看完整能力；裝備卡的「能力比較」會預覽攻擊、攻速、射程、防禦及恢復等實際變化，有利用綠色、不利用紅色，並搭配數值與箭頭。比較不會裝備或消耗道具；選「裝備」才生效。已損壞裝備停止加成，面板呈現失效後能力。
