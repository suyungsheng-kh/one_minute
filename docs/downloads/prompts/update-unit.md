# 完整工作流提示詞

<a id="update-unit"></a>

## 更新既有系列或單元｜修改到重新上架

從目前正式版本接續動畫修改，沿用品牌，整合網站、技術經驗、提示詞與 skill，檢查後重新發布。

### 使用方式

1. 填入更新目標、專案位置或課程網址、修改需求、必須保留的內容與 animation 工作區絕對路徑。
2. 範本預設完成必要修改、重新輸出與 GitHub 發布；若只要檢查、分鏡或預覽，先修改任務及最後的授權段落。
3. 複製到新對話，使用 $one-minute-production 從既有正式專案接續；保留課程 id、成功素材、舊連結、觀看紀錄與歷史版本。

### 完整提示詞

```text
請使用 `$one-minute-production` skill，更新「一分鐘認識」既有系列或單元，完成必要的動畫修改、網站整合與發布。

更新目標：【系列名稱／課程名稱／既有課程 id】
專案位置或課程網址：【已知位置；不清楚時請從正式目錄確認】
這次要修改：【具體問題、希望的前後差異與完成條件】
必須保留的內容：【指定內容；未指定時保留既有正確內容、成功素材與歷史版本】
工作區：【animation 工作區絕對路徑】

請先閱讀工作區、one_minute、所屬系列及 portal 的 AGENTS.md、共同品牌規範、專案 README、分鏡／講稿、正式 release 設定、生成器、trace、配音字幕對時資料及既有 review。確認目前正式版本、實際需求與受影響範圍後，在原正式專案接續修改，不另建重複專案，不任意重跑 setup 或升級工具。

請完成以下工作：

1. 動畫修改：依本次需求修改正式來源及必要的分鏡、講稿、trace、畫面與字幕。沿用核定規格、聲音與成功音訊，優先只修改受影響部分；確有新配音需求時遵守工作區共用 Azure 用量管控，不為預覽或測試重配成功旁白。重新輸出使用新版本檔名，保留原素材、歷史版本及可重建資料；確認新版後才更新正式版本設定。若本次僅改文件或網站，按實際範圍處理，不重製無需變更的影片。

2. 品牌一致：沿用「原版的活潑構圖＋新版的品牌配色」：霧白、墨綠主品牌，藍黃輔色，圓形襯底、白紙卡、星芒、手繪箭頭與圓角標籤。網站、封面、技術文章及提示詞庫使用既有共用模板；動畫依本次修改延續原有教學與品牌設計，不為統一網站而重製未受影響的歷史影片。署名「一分鐘認識」，主軸「一分鐘，認識一個概念」。

3. 網站整合：同步更新受影響的首頁推薦、課程目錄、觀看路線、課程頁、品牌封面、影片、字幕、實際片長與下載；核對上一集／下一集、版本切換及進度接續。保留既有課程 id、舊連結與觀看紀錄，不建立重複入口。檢查與既有單元的合理關聯，將新版導讀與相關單元連結同步補入文件、課程頁及觀看路線，必要時更新反向連結與概念關聯圖；保留仍正確的內容，不牽強串接。

4. 技術經驗與 skill：將本次實際可複用的方法、問題與修正、適用條件及驗證結果，同步整理至技術文章、提示詞庫與 one-minute-production skill，更新案例、技能參考檔、使用說明及下載包，必要時同步本機已安裝版本。正文維護唯一來源，區分已驗證方法與待驗證想法；沒有新經驗時記錄原因，不重複堆疊文章，也不公開原始對話、憑證或私人帳本。

5. 檢查與交付：依修改範圍檢查動畫概念與操作、trace、聲畫字幕對時、正式 MP4、素材引用、播放與跳轉、字幕下載、網站導航、搜尋篩選、觀看進度、品牌、手機、鍵盤、提示詞完整複製、skill 下載與離線操作。完成必要的建置及打包，先修復問題，再更新正式發布。檢查紀錄寫本次實際結果及限制，不沿用舊 QA 冒充新版驗證。

本次授權完成上述必要修改、重新輸出、網站及技術資料整合，檢查後正常推送至 https://github.com/suyungsheng-kh/one_minute 的 main。推送前確認並妥善合併遠端更新，不強制推送，不上傳備份、憑證、私人帳本或動畫原始製作專案。確認 https://suyungsheng-kh.github.io/one_minute/ 已顯示本次更新後，提供修改摘要、保留項目、正式課程與路線連結、檢查結果及提交紀錄。
```
