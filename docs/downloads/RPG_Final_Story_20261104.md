## 故事主軸

替旅人留一條回家的路，也讓守望的人有人接班。

指引旅人往來的星燈陸續失去回應。村莊有人迷路，港口的藥箱送不出去，北方要塞仍守著最後的航標。從青苔村出發的旅人循著星光、手記與求援，走過三章互通的世界。

最初的目標是找回星片、點亮燈臺。沿路的人與記錄卻讓旅人發現：守護若只由一個人承擔，燈再亮，也可能等不到下一個接手的人。

故事逐步從救回眼前的人，走向恢復彼此往來的道路，最後回到同一個問題：當星光重新亮起，誰願意替下一位旅人留燈？

## 第一章・熄滅的星燈

青苔村的星燈熄滅，採藥、送信與回家的道路開始失去方向。苔爺交付求助，阿嵐協助旅人準備出發。

### 1．青苔村

旅人在青苔村完成出發準備，聽見伊娜與森林的淵源。伊娜不是自動加入的隊友：先接下她的請託，之後解放根影洞窟的巨靈並取回星片，回村讀完回報故事，她才真正同行。

### 2．微光森林 → 失路者的林徑 → 樹根的記憶 → 根影洞窟

微光森林保留著村民進山的箭頭與老師教人點亮火花的刻痕。樹根記憶中的黑雨與未完告別，帶出星燈失衡的疑問。旅人點亮根燈、驅散巨靈身上的陰影，取得林之星片與通往遺跡所需的古銅鑰匙。

### 3．月溪渡口 → 漂木長廊 → 失聲的泉眼 → 沉水石窟

月溪渡口的木橋、藥箱與水源彼此牽連。旅人收集木材修橋，整理漂木長廊的貨物、調整泉眼與水閘，再擊退濁流之主、取得溪之星片。露米的加入同樣需要先接個人故事、完成副本、回原地聽完回報。

### 4．月溪渡口・月溪藥屋

漂木長廊接通、藥草單交回原旅人後，月溪藥屋復甦。可選回訪讓青葉在出門採藥時也能替送藥人留門與留燈。門鎖、留夜燈、安全燈修好後，屋簷下出現歇腳的人，帳本也留下完成後的回應。

### 5．靜鐘遺跡 → 守塔人的書庫 → 雙影階梯 → 迴音鐘樓

靜鐘遺跡保存守塔人的信與未被聽見的求救。古銅鑰匙來自森林星匣，不需要尋找額外的隱藏鑰匙。旅人讀取書庫、找回影鈴，讓鐘聲依月、星、日重新回應，取得塔之星片。

### 6．星燈古堡

三片星光讓星燈古堡的封印回應。失落的守燈者平靜後，旅人仍需調查星燈核心，第一章才真正完成。海面上的符文與風鈴港求援信揭示：古堡只是三座燈臺之一，下一段旅程必須越過海峽。

**章末銜接：**第一章完成後，由青苔村星舟領航員前往第二章。若伊娜或露米尚未加入，仍可回訪完成她們的約定；手記以記錄或旅人的觀察呈現，避免未同行的人突然開口。

## 第二章・霧海的回聲

霧海切斷風鈴港與外海，漁船停泊、藥草無法送達，居民開始懷疑燈臺的守望者。追尋老師的線索與找回送藥航道，在這一章匯成同一條路。

### 1．風鈴港 → 灰燼林地 → 燒焦的邊境

港口需要藥箱與能重新出航的標記。灰燼林地留下老師的話：封印不是永遠關門，而是替尚未準備好的人爭取時間。這段線索讓旅人開始理解，老師的離開與封住星脈並非簡單的拋棄。

### 2．餘火迷廊 → 織火者的巢

餘火迷廊的守路石像按符石安排循道推石、壓住踏板，旅人過橋轉動石柄，救出巡守者。東南石壁留著老師第三頁。織火者的巢保存第一枚潮印；首領平靜後仍需調查誓印，才算取回約定。

### 3．餘火迷廊 → 灰燼林地・引路燈庭

可選的修繕線接在原橋修復之後。旅人找出巡路副本多抄的一枚轉向，修好副本，喚醒另一座石像；原守路者繼續壓住踏板。新石像在引路燈庭學會照看四站、在歸路旗前停止，也修好漏掉前進而原地徘徊的舊約定。送藥人因此有路可走。

### 4．鏡沼 → 失去名字的渡口 → 反照水室 → 無人的巡禮

鏡沼讓旅人面對失去的名字、沒有做出的選擇與歸途船票。倒影可以提醒過去，卻無法代替仍要前行的人。巡禮之印回應後，第二枚潮印升起；找回航標零件並交還修船人、完成藥箱回報，也能恢復港口與鏡沼之間的渡船。

### 5．暮砂遺城 → 被沙掩埋的市集 → 停住的午後 → 守將的最後一班崗

暮砂遺城仍停在商隊沒有抵達的午後。旅人可把水留給眼前的人，或帶水繼續尋找出路；兩個選擇都能前進。守將放下最後一班崗，旅人取得第三枚潮印，也看見守護不應只剩下不讓人通過的命令。

### 6．風鈴港・沿岸貨棚 → 灰燼林地・航記小屋 → 灰燼林地・東岸避風所

恢復的航線讓補給有機會送達。港口三種設備各自整理一批藥箱，回報後可再幫一箱晚到的三號貨插入原隊列。老師的兩套索引共同指向八十三號避風所，倖存旅人的回應補上老師為未上船的人爭取一夜的往事。之後的八十四號回信確實查無於舊冊；新航記與旅人說明，那是霧潮後才設立的臨時安置點。

### 7．霧海燈臺・外環 → 霧海燈臺・守望長廊 → 霧海燈臺・燈心

三枚潮印讓霧海燈臺回應。長廊呼應港口風鈴、灰燼手記與霧岸等藥的人，不提前引用第三章的糧袋。旅人擊退霧潮守望者後，仍要調查東側燈心，航道才真正恢復。手記的動機得到印證，而正在崩解的封印把旅程指向北方。

**章末銜接：**第二章完成後，由風鈴港領航員前往晨星要塞。已完成巡燈的人，可先在燈庭命名與試行一份引路約定，再把同一段方法帶往第三章。

## 第三章・歸途的約定

晨星要塞仍有燈火，城外卻已失去風聲。人們等待最後的補給與航標，旅人必須找回風、記憶與守護三份誓約，才能走向歸途之塔。

### 1．晨星要塞 → 斷穹山道 → 最後的運糧路 → 雲上的回聲 → 風之誓約

斷穹山道保存運糧路、被風吞沒的呼聲與另一封老師的信。勇氣不只在於獨自面對危險，也包括願意讓人同行。風之誓約回應後，山道再有車輪聲；水渠疏通、糧袋交回要塞，公共糧棚也會為下一位旅人準備飯。

### 2．晨星要塞

可選的引路約定讓第二章的方法有人接手。玩家自行命名並安排跨步、點燈、敲鈴；只有抄寫不會讓石像行動，喚醒後才執行，再接續外面的巡路安排。跨兩格巡三站與跨三格巡兩站都到第六格，卻留下不同鈴聲。回報後，接班石像出現在要塞，守路人能準備回家。

### 3．無聲王庭 → 未寄出的信廊 → 沉默的宴席 → 王座留下的答案

無聲王庭裡有未寄出的信、始終空著的位置與依靠沉默維持秩序的王座。旅人讓被省略的名字重新被記得，承認過去曾有遺憾。記憶的誓約不要求遺忘，而是讓仍活著的人可以繼續說話。

### 4．天光聖域 → 守護者的門庭 → 光與影的選擇 → 第三份誓約 → 天光聖域・交班側殿

天光聖域門庭需要日、月、星三枚誓印與連動石環。門外的求援刻痕質疑只有完美者才配守光的規則。側殿的交班儀式讓玩家把小塔的光逐段交出去；守燈者留下的記憶終於有人接住。接著，玩家可選讓願意同行的人共守，或先帶著責任往前走。兩者都能取得守護的誓約，結尾會回應當時的選擇。

### 5．歸途之塔・外環 → 歸途之塔・守望長廊 → 歸途之塔・燈心

三份誓約齊備後，歸途之塔開門。外環承接已取得的約定，不重新要求玩家尋找同一份誓約。最後燈心仍被吞光之影阻擋：擊退陰影只是清出最後一段路，必須再調查核心，三座星燈才會真正彼此回應。

### 6．晨星要塞 → 灰燼林地・引路燈庭 → 月溪渡口・月溪藥屋

通關與回訪讓路上的成果留下來。送藥人能沿燈回家，藥屋屋簷有乾毛巾與等候的位置，接班石像接住巡路約定，新航記保存舊冊沒有的人名。晨星要塞的回信集只收錄已完成的相遇；結尾以玩家真正做過的事回應，不替未完成的支線虛構成果。

**章末銜接：**旅人可以沿自己點亮的路回家，也能回訪未完成的約定。已選的分歧路線會保留；補回夥伴、信物與原委託後，可以從手札重溫符合新進度的結局。

## 支線如何接回主軸

### 無人值守的避雨處

月溪藥屋復甦後，青葉擔心自己採藥時送藥人無處等雨停。

三組裝置修好並回報後，屋簷有送藥人歇腳，帳本與藥師對話留下後續。

### 修符石 → 補回引路燈 → 引路約定

原守路石像仍須守橋，另一份巡路副本卻走錯方向。

修復、巡燈、命名與交接形成一條接續故事；送藥人有路可走，第三章有人接班，守路人能回家。

### 藥船三批貨與晚到的一箱

渡船恢復後，沿岸藥箱需要依到站順序裝妥；出航前又多一箱晚到貨。

貨物確實送達，回信更新。晚到箱只是一段短事件，不重做原三批貨。

### 老師索引、八十三號與舊冊之外的信

老師第三頁指向八十三號，後來的回信卻寫著舊冊沒有的八十四號。

找得到與查無都成為有效發現；避風所與新航記補上老師替晚到的人留燈的往事，不另補寫老師生死。

### 守燈者的交班儀式

聖域門庭三環回應後，側殿留下曾經不敢放手的守燈者與三座燈柱。

一、二、三盞分段交接，讓小塔先有人接住；回報後留下守夜的人也能回家的記憶。四盞可回訪重演。

### 藥屋、渡船與公共糧棚

補給、航標、水與糧食必須真的回到人們生活中。

原委託與探索工具推動設施復甦，讓同一主線上的道路與補給互相支持。

## 三章的可選分歧

每章在聯絡人處選一條路線，完成現場事件後回報。救助與調查都能繼續同一主線；同一存檔會保留已選路線。

| 章節 | 救助路線及成果 | 調查路線及成果 |
|---|---|---|
| 1 | 先救被困的採藥人：採藥人的藥籃回到村裡，等待藥草的孩子們度過了平安的一夜。 | 先追查林影的足跡：哨所的記錄被帶回青苔村，巡林員替後來的旅人補上了根燈與巨靈的警示。 |
