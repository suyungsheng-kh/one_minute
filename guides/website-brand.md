# 一分鐘認識：網站共同結構與品牌規範

主品牌為「一分鐘認識」，首頁主標「把好奇，變成理解」，主軸為「一分鐘，認識一個概念」。以生活與遊戲例子解釋單一概念，內容難度以國中生為背景設定。網站不反覆以年齡作宣傳，也不暗示一分鐘就能精通。

## 所有系列共用的結構

正式動線為「首頁 → 觀看路線 → 課程頁」。首頁推薦、搜尋和概念關聯圖可直接開啟同一套課程頁；不另建系列學生網站。

- 首頁：共同品牌、推薦、概念關聯圖、觀看路線、全部課程與學習方式。
- 觀看路線：系列介紹、學習目標、實際片長與進度、觀看順序、跨單元關聯及回顧問題。
- 課程頁：生活問題與學習目標 → 先讀懂，再看動畫（說明、例子、觀察步驟、提醒、觀看任務）→ 影片與共用播放工具 → 一句重點 → 跨單元關聯 → 小練習與動手挑戰 → 概念比較／整理 → 下一集與完整觀看路線。

每集均有 guide、connections 與對應的 comparison；內容以課程實際概念為準，不為湊格式重複文案。比較表可用來整理同系列三集的不同問題，也可比較方法，並以課程 id 連回對應單元。

## 共同視覺與操作

- 三種頁面共用 assets/style.css、品牌圖示、暖米白背景、深綠文字、字體、按鈕、卡片、間距及響應式規則。
- 頁首導覽一致為「概念關聯圖、觀看路線、全部課程」，頁尾固定「一分鐘，認識一個概念。」。
- 所有課程都提供原生播放器、重看、0.75 倍播放、影片／現有字幕下載與觀看紀錄；答題不會自動標示看完。
- 演算法以珊瑚色、Scratch 以綠色、排序與搜尋以藍色、河內塔以暖橘色輔助辨認。主品牌、模板與主要操作一致，系列顏色不變成另一套介面。
- 特定內容可增加同步提示、補充辨識題或版本切換。排序保留 60 秒配音版與 30 秒原版；其他系列不增加沒有實際內容的空白功能區。
- 歷史動畫畫面保留原版設計，網站外框與課程結構負責維持共同品牌。

## 後續維護與檢查

### 共用課程封面（2026-10-18）

首頁與觀看路線使用同一套 1280×720 向量封面：左上為「一分鐘認識」與共用品牌圖示，左側是課程大標題與一句說明，右側為統一筆觸的概念插圖，系列配色、標籤與集數協助辨認；頁底固定「把好奇，變成理解。」。目前公開署名維持「一分鐘認識」。

來源為 catalog 的 coverDesign（titleLines、subtitle）及 tools/brand-covers.cjs，Logo 直接取自 assets/mark.svg。標題最多兩行、每行最多七字，說明最多二十三字；新系列可沿用預設插圖，再按教學概念擴充。建置產生 covers/<id>.svg，公開 catalog 的 cover 指向該檔；不要手改生成圖檔。

影片 poster 仍保存原始畫面，供播放器使用；cover 專供課程卡片與觀看路線，讓封面視覺保持一致。封面不遮上中央播放鈕，片長保留在課程卡片文字區。tools/check-covers.cjs 檢查全部封面、文字界線、搜尋分類、手機、離線與課程導航。

新增單元沿用 lesson.html、path.html 與 catalog，可複製 lesson-template.json 的 guide 骨架；comparison 範例預設 scratch-data，必須改為該課程適用的整理表。保留固定課程 id、舊網址及觀看進度。共用結構修改後執行 build、check、package，確認所有已發布課程的區塊順序、共同導覽、影片工具與手機版；排序另檢查兩個版本的片長、字幕和提示切換。

各系列的首頁、路線及課程內容須在同次更新整合；檢查通過後匯出並正常推送 GitHub，確認 Pages 已更新。自動檢查結果保存在 review/qa.json 與 review/narrated-check.json，品牌代表頁截圖為 review/brand-<series>.png。

## 動畫製作技術閱讀系列

同品牌新增技術文章、提示詞與 one-minute-production skill，沿用背景、Logo、字體、卡片與導覽。首頁入口為 production 區塊，完整閱讀路線在 production.html，文章模板為 article.html。技術文章不計入已完成動畫集數；案例指向已發布課程，並提供適合的反向入口，觀看紀錄維持原意。

正文與提示詞維護 content/production.json，技能來源在 ../production/skill；同步後由 build 產生可離線閱讀的資料、Markdown 與技能 ZIP。保持公開署名「一分鐘認識」，引用案例與現行規則，不公開原始對話或私人資訊。
